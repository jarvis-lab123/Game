# Voki Phase 2 – Implementation Plan

> **For agentic workers:** Native execution + parallel subagents for isolated modules (sync, stats/export, tray). Steps use checkbox syntax.

**Goal:** Voki komplett: Lernsession nach Zeit mit Gruppen, „sitzt / wackelt“-Erkennung, Handschrift-, Hör- und Hinweis-Modus, Eselsbrücken-Werkstatt, Fehlerheft, Probetest mit Note, Statistik, TSV-Export, Wischgesten, Sync über GitHub-Gist, Tray-Icon.

**Architecture:** Wie Phase 1: reine Logik in `src/lib` (TDD), Dexie v2 (+ `tests`, `tombstones`), Screens in `src/ui/screens`. Sync = pull → merge (pure, getestet) → push eines geheimen Gists; Gist-Client bekommt `fetch` injiziert.

**Tech Stack:** bestehend + Recharts (Statistik), qrcode (Sync-Code als QR), @tauri-apps/api (Tray-Befehl).

**Spec:** `voki/docs/VOKI_KONZEPT.md` §5.4b, 5.4c, 5.7, 6.4, 7, 9 Phase 2 + Nutzerwünsche vom 16.11. (Zeit-Abfrage + Gruppen, Handschrift-Modus, sitzt-Erkennung, visuelle Eselsbrücken, Sync über GitHub statt Supabase, kein Login).

## Global Constraints
- 0 CHF. Keine Server ausser GitHub (Gist-API, CORS-fähig). Token nur Scope `gist`, bleibt auf dem Gerät, nie im Backup.
- Minimalistisches Design: bestehende Tokens/Komponenten, ein Akzent, keine neuen Farben ausser Genus-Tönen.
- Probetest-Note: Schweizer Skala linear, 6 bei 100 %, 4 bei 60 % → `1 + 5·p`, auf 0.5 gerundet (min 1).
- Hinweis-Leiter: 1 Hinweis → Good→Hard; ab 2 → Again.
- Gruppen: max. 5 neue Wörter pro Gruppe (Chunking 4±1), Zeit nach Schätzung (Review 10 s, neues Wort 45 s).

## Review Focus
1. Sync mit leerem Gist / kaputtem Gist-Inhalt / 401 (Token falsch) → klare Meldung, lokale Daten unverändert.
2. Gerät A offline gelernt, Gerät B hat inzwischen gepusht → nach Sync beide Logs vorhanden (Union), keine Karte rückwärts.
3. Gelöschtes Wort auf A, unverändert auf B → nach Sync auf beiden weg (Tombstone).
4. Gewählte Zeit kleiner als eine Gruppe → mindestens eine kleine Gruppe, nie leere Session.
5. Probetest mit < 20 Karten im Deck → nimmt alle vorhandenen, Note korrekt.

### Task 1: Schema v2 — `src/db/db.ts`, `src/lib/types.ts`
- Note += `emoji?: string`, `sketch?: string` (PNG-DataURL ≤ 60 kB), `story?: string`.
- Neue Tabellen: `tests: 'id, deckId, date'` (`TestResult {id, deckId, date, total, correct, grade, items: {cardId, typed, correct, confident}[]}`), `tombstones: 'id, table'` (`{id, table, deletedAt}`).
- `deleteDeck/deleteNote/syncDirections` schreiben Tombstones. Test: Löschen erzeugt Tombstone.

### Task 2: Logik (TDD) — `src/lib/mastery.ts`, `groups.ts`, `hints.ts`, `mnemonic.ts`, `grading-test.ts`
- `noteMastery(cards, logs, now): 'neu'|'lernt'|'wackelt'|'sitzt'` — sitzt: alle Karten review, Stabilität ≥ 7 d, letzte 2 Antworten richtig; wackelt: leech oder ≥2 Fehler in letzten 5 oder R(now) < 0.8.
- `planGroups({reviews, fresh, cram}, minutes): Group[]` — Wörter (Notes) gebündelt, max 5 neue/Gruppe, Summe ≤ minutes (mind. 1 Gruppe).
- `hintText(answer, level 1..3, example?)`, `applyHints(rating, hints)`.
- `suggestMnemonics(note, otherNotes, language): Suggestion[]` (Genus-Endungen, Wortteile, ähnliche Wörter anderer Sprache/Deutsch).
- `swissGrade(correct, total)`; `pickTestCards(cards, n=20, rng)`.

### Task 3: Session v2 — `SessionSetup.tsx`, `Session.tsx`, `cards.tsx`, `HandwritingPad.tsx`
- Start-Sheet: Zeit (5/10/15/25/40 Min), Modus (Tippen · Handschrift · Hören · Umdrehen), Deck.
- Gruppen nacheinander, Zwischenbildschirm „Gruppe 1 geschafft“.
- Handschrift: Canvas (Finger/Stift/Maus) oder „auf Papier“, Lösung zeigen, selbst bewerten Falsch/Fast/Richtig.
- Hören: TTS liest Fremdwort, tippen. Hinweise mit `H`/💡. Problemwort-Pause mit Eselsbrücken-Werkstatt. Wischgesten im Umdreh-Modus.

### Task 4: Eselsbrücken-Werkstatt — `MnemonicStudio.tsx`
- Vorschläge, Emoji-Auswahl, Skizzenblock, eigener Satz, Genus-Farbe; in Intro, Problemwort-Pause, Wort-Editor. Claude-Prompt „Eselsbrücken für meine wackligen Wörter“ + Rück-Import (TSV term⇥Eselsbrücke).

### Task 5: Üben-Screen — Fehlerheft + Probetest
- Fehlerheft: Problemwörter + Falschantworten 14 Tage, Drill (MC → Tippen, ohne FSRS-Wirkung).
- Probetest: 20 Karten, nur Tippen, strenge Akzente, keine Hilfe, vorher „sicher/unsicher“; Auswertung mit Note, Überschätzt-Liste → Fehlerheft (Tag `überschätzt`); Verlauf.
